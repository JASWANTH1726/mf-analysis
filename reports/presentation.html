Problem Statement

India has 44+ AMCs and over 2,500 mutual fund schemes. Retail investors have no easy way to compare funds on risk-adjusted returns, portfolio overlap, expense ratios, or manager track records — all in one place.

  • NAV data scattered across AMC websites
  • No unified view of risk metrics vs returns
  • SIP performance hard to track historically
  • Portfolio overlap between "different" funds is invisible

Project Goal

Build a structured data pipeline that ingests, cleans, and organises mutual fund data — enabling fund comparison, risk profiling, and SIP analysis through a single codebase.

AMFI Scheme Code Structure

Each scheme variant — Direct Growth, Regular Growth, Direct IDCW, Regular IDCW — gets its own unique 6-digit AMFI code. So a single fund can have 4+ codes. This is why code 119092 (labelled "Axis Bluechip") returns "HDFC Money Market Fund" from the API — the code maps to a specific variant, not just the fund name.

Anomaly Noted — Live NAV API

The mfapi.in API returns scheme names that don't always match the label used to query. For example, code 119092 (queried as "Axis Bluechip") returns "HDFC Money Market Fund" in the response metadata. This is expected — AMFI codes are variant-specific, not fund-name-specific. Always use the scheme_name field from the API response as the source of truth, not the label used to fetch it.
